# Git pathspecs for everything whose contents feed the built
# inspect-sandbox-tools binary. A change to any path listed here must be paired
# with a bump of sandbox_tools_version.txt (otherwise the published artifact
# would silently change meaning). This is the single source of truth for that
# rule: the CI gate (the `detect-slow` job in .github/workflows/build.yml) and
# the runtime install-state check (_check_main_divergence in sandbox.py) both
# read this file, so a change is classified the same way in CI and at runtime.
#
# Full-line `#` comments and blank lines are ignored. Entries use git pathspec
# syntax, including `:(exclude)` magic, and are passed to `git diff -- ...`.
#
# The package source. Its pyproject.toml is the dependency spec the builder
# installs; the whole `src/` tree is bundled. Docs, design notes, and tests
# under it are not in the binary, so they are excluded.
src/inspect_sandbox_tools
:(exclude)src/inspect_sandbox_tools/tests
:(exclude)src/inspect_sandbox_tools/design
:(exclude,glob)src/inspect_sandbox_tools/**/*.md
